# Students belong to the college, not to a branch

A student has a home branch (where they registered) but belongs to the whole college, so one person keeps one student ID and can take skills at any branch without registering again. Branch staff still only work with their own branch: they browse students registered there or taking a skill there, and only ever see enrollments at their branch. The one exception is an exact student ID or phone lookup, which finds a student from any branch so staff can enroll them instead of registering a duplicate.
